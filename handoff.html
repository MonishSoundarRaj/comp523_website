Project Handoff

Application overview, setup requirements, ownership, hosting, and ongoing costs for the LIGHT website.

Application overview

LIGHT helps people find information about nearby local libraries through a conversational search experience.

Users provide a ZIP code. The application uses it to identify nearby libraries and search the corresponding database for relevant information. A Claude chatbot turns the database results into a clear response in standard English and includes a confidence score indicating how accurate the response is expected to be.

We will provide the client with links and ownership to all necessary tools.

What the application uses

Supabase database

Stores the library information used to answer searches. The team can help provide access to the existing database or set up another instance if desired.

Claude API

Provides the chatbot functionality. To continue using Claude, create an account and replace the API key in the .env file. The team can help configure another chatbot, such as OpenAI or Ollama, if preferred.

Website hosting and source code

The site is currently hosted through GitHub Pages from a repository held in a team member’s personal account. The team can transfer ownership or create a copy for the client. Hosting can remain on GitHub Pages, move to Carolina CloudApps, or use a personal hosting device. Carolina CloudApps may require client approval before the team can assist with setup.

Costs and scaling

At the current scale, the Claude API is the only expected cost, and it is minimal. If usage grows, database and hosting charges may apply. Free hosting options such as GitHub Pages or Carolina CloudApps can avoid hosting charges.
