3. Regression testing

  • All tests run with one command, npm test, before every commit.
  • The reviewer runs it again on every pull request. If a test fails, the change is not merged.
  • Every bug fix comes with a new test, so the bug can't come back.

How to run the tests

The code and its tests are in github.com/MonishSoundarRaj/light. From its main folder:

npm install
npm run setup     # installs Python packages, checks the database
npm test          # runs all automated tests (Vitest, then pytest)
npm run dev       # starts the app for the manual tests

The automated tests need no database or API key. The manual tests need a .env file with the database address, the Claude API key, and the admin password. The repository's README lists every setting, and we will give the values to graders on request.
